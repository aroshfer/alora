## What you should do now

You **don't need to run `git init` anymore**.

When you change your project, use:

```bash
git status
```

Then:

```bash
git add .
```

Then:

```bash
git commit -m "Describe your changes"
```

Then:

```bash
git push
```

For example:

```bash
git add .
git commit -m "Update Alora UI"
git push
```

### Before starting work
